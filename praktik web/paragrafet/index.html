HTML (HyperText Markup Language) është gjuha standarde që përdoret për krijimin dhe strukturimin e faqeve web. Me HTML mund të vendosim tituj, paragrafë, imazhe, lidhje, tabela, lista dhe elemente të tjera në një faqe interneti. HTML përdor etiketa (tags) për t'i treguar shfletuesit se si duhet të organizohet përmbajtja. HTML zakonisht përdoret së bashku me CSS për dizajnin dhe JavaScript për funksionalitetin e faqes.
